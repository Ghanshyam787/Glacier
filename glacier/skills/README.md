# Glacier Skills

Is folder mein daale gaye skills Glacier khud load karta hai (restart par).

* `*.md` / `SKILL.md`  -> instructions (kaise kaam karna hai). Glacier inhe padh kar follow karta hai.
* `*.py`  -> nayi tools. File mein `from registry import tool` karke `@tool(category="mine")` lagao.
  Dekho `example_skill.py`.

Python skills sirf haath se copy karo (internet se install nahi hoti - safety).
